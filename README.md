# משמרות קורטדו — אפליקציה עצמאית

אפליקציית משמרות לעגלת הקפה, שרצה על Firebase ולא תלויה בשום כלי אחר.
העובדים פותחים קישור, נכנסים עם חשבון גוגל ומשתבצים מהטלפון.

**הקמה: ראה [SETUP.md](SETUP.md).** בערך 15 דקות, הכול בלחיצות באתר.

## מה יש בפנים

| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה הדף |
| `styles.css` | עיצוב, כולל מצב כהה |
| `app.js` | כל הלוגיקה: כניסה, משמרות, שיבוץ, שעות פתיחה |
| `config.example.js` | תבנית להגדרות. יוצרים ממנה `config.js` |
| `firestore.rules` | כללי האבטחה של מסד הנתונים |
| `manifest.webmanifest`, `sw.js`, `icon-*.png` | התקנה בטלפון ופתיחה מהירה |

## מה האפליקציה עושה

- **מנהל:** בונה את שבוע המשמרות, מעתיק משבוע שעבר, פותח וסוגר שיבוץ, מסיר עובדים ורואה כמה מקומות מאוישים.
- **עובד:** רואה את השבוע, משתבץ ומבטל, ורואה למה הוא רשום.
- **שעות פתיחה:** מחושבות מהמשמרות המאוישות, עם כפתור להעתקת טקסט מוכן לפרסום.
- **בטלפון:** אפשר להוסיף למסך הבית, והדף נפתח גם כשהרשת חלשה.

## מבנה הנתונים (Firestore)

- `weeks/w<YYYY-MM-DD>` — `{ shifts: [{id, day, start, end, need}], open: bool }`
- `signups/<week>_<shift>_<uid>` — `{ week, shift, uid, name, photo, at }`
- `users/<uid>` — `{ name, email, photo, lastSeen }`

## מה עוד לא כאן

תזכורות אוטומטיות, פרסום לרשתות ולוח התוכן נשארו בינתיים בכלי שרץ ב-Claude.
אפשר להוסיף אותם כאן בהמשך עם Cloud Functions ו-Cloud Scheduler.
