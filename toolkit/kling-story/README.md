# סטורי "פתוחים היום" — הפורמט מ־31.10.2026

הבעלים, 31.10.2026: "ככה אנחנו מהיום מפרסמים את הסטורי שלנו". כל השעות וכל פרסום השעות בצורה הזאת: סרטון Kling של משהו מהעגלה שזז (עכשיו: קפה קר עם הלוגו של סבתא וקש שחור, מול העגלה עם אנשים), ועליו השעות, הקווים, הברקודים ו"כולם מוזמנים". הנושא מתחלף לפי הזמן (פיצה, שייק וכו') — כל נושא חדש = קליפ בסיס חדש מ־Kling.

## לבנות סרטון ליום

```bash
cd toolkit/kling-story
echo '{"day":"ראשון","date":"1.11","times":["09:00–13:00","15:00–19:00"]}' > today.json
python3 overlay_today.py today.json layers ../assets/fonts qr     # שכבות שקופות 1080x1920
bash make_today.sh layers out.mp4                                 # 8.04 שנ', H.264 + AAC, ‎-14 LUFS
```

השעות רק ממה שפורסם דרך בוט קורטדו (`public/hours` / דף הנחיתה), לעולם לא מנחשים. יום סגור — אין סטורי.

| קובץ | מה |
|---|---|
| `base-coffee.mp4` | קליפ הבסיס מ־Kling (v4, 8 שנ', מצלמה קבועה). נבנה מהתמונה של הבעלים של העגלה עם אנשים |

| `overlay_today.py` | כותרת, תאריך, שעות (מתחת לפס העליון של הסטורי), ברקודים בטור ימני על הדשא (ויז, וואטסאפ, אינסטגרם — נבדקו שנסרקים), "כולם מוזמנים" משמאל לכוס |
| `lines.py`, `lines/` | שני קווים דקים בטרקוטה שנמתחים מימין לשמאל, פעמה אחת כל אחד |
| `make_today.sh` | מרכיב הכל. כל כניסה על פעמה של 125 BPM (פעמה 0.48 שנ', ראשונה 0.47) |
| `soundtrack.wav` | הרקע של Kling + ציפורים (`birds.py`) + מנגינת בית קפה שמחה (`../reel/music.py --style cafe --seed 37`, מואצת ×1.488 ל־125 BPM, עם שכבת אוקטבה) |
